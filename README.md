# R-Delay

SIS 기반 해상·육상 지연 예측·대응 웹서비스 프로젝트.

현재 단계: 실행환경 확인 및 제출·설계 문서 v0.1 작성. 서비스·수리모델 엔진 구현 완료를 의미하지 않습니다.

이 저장소는 최초 확인 시 파일과 브랜치가 없는 빈 저장소였습니다. 작업 브랜치를 만들기 위한 최소 초기 커밋만 기본 브랜치에 생성합니다. 문서 생성 원본·검사 기록·산출물 작업은 `codex/rdelay-bootstrap` 브랜치에서 진행합니다. 자동 병합·외부 배포·공개 범위 변경은 하지 않습니다.

개인정보·서명·재학증명서·비밀키는 저장하지 않습니다.
