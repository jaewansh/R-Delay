실행·모델·코드 버전과 실제 검사 기록
Python 엔진은 한 곳에서 계산하고 웹은 API 응답을 표시한다. 실제 화면은 HTML/CSS/JavaScript, API 는 
FastAPI 다. React 는 사용하지 않는다. 컨테이너 설정은 있으나 Docker 실행 검사는 미수행이다. 온라인과 로컬
은 같은 엔진을 사용하고 캐시 화면이 아니라 인터넷 없이 새 계산이 되는지 확인한다.
GitHub 에는 engine/api/web/tests/experiments/docs 와 합성자료를 분리한다. 공개 저장소에 서명·증명서·연
락처·비밀키를 넣지 않는다. 코드·문서·실행 버전을 고정하고 검토 없이 main 을 병합하거나 공개설정을 바꾸지 않
는다.
