기획 배경
부산신항–양산권 수입컨테이너 운송을 적용 후보로 삼는다. BPA 의 차량 예약 운영 사례[W1]와 공개된 
연결 시뮬레이션 요구[W2]를 참고하여 해상 지연과 내륙 마감의 연결 문제를 다룬다. 실제 고객·화물 연
결자료는 미확보다.
제안 작품 핵심 컨셉
SIS 미분방정식으로 거점의 지연 전파·회복을 계산하고 로그-OU 로 계수 변동, 입자필터로 관측 갱신을 
구현한다. 시간가변 선석 대기모형을 화물 준비·반출·도로 이동과 연결해 마감 위험과 대응 비용을 비교
한다. 원래 마감과 차량·예약·변경 시한을 유지하며, R_d 를 단독 안전기준으로 쓰지 않는다. 원안 식과 
추가 연결 가정을 구분한다.

및 계획
2 거점 합성 웹·Python API 시제품과 SIS·로그-OU·입자필터·선석 대기·배차 계산을 구현했다. 회복률 하
나의 추정과 자동검사를 포함한다. 본선에서는 외생변수 학습, 관측 확장, 사용성·민감도 검증을 보강한
다. GitHub Pages 의 브라우저 직접 계산은 전환 목표이며 아직 미구현이다.
비즈니스 모델 및 사업
화 방향
내륙운송을 조율하는 중소 포워더 운영담당자를 사용자 가설로, 운영책임자를 구매자 후보로 둔다. 사업
장·관리건수 기준 구독을 검토한다. 공개자료로 업무 가설을 정리하고 연결자료의 이용권 확보 후 제한 
파일럿으로 입력 부담·반복 사용·구매자 편익을 확인한다. 가격·고객·매출은 미검증이다.
