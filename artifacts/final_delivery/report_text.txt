대기는측정가능한운영문제
BPA 가 발표한 BPT 신선대·감만의 과거 VBS 시범운영에서 평균 대기시간은 28.23 분에서 23.93 분으로 변화했
다(2022.1.27). 특정 기간 전후의 발표 결과다. 독립적으로 인과효과를 식별한 실험, R-Delay 의 성과, 현재 신항 
운송 평균으로 바꾸어 쓰지 않는다.
[W2] 
 
 
 
 
실제이용자의연결시뮬레이션요구
BPA–MSC 협의 공개자료(2026.4.13)는 환적 연결 시뮬레이션과 터미널 간 운송 통합정보 등의 고도화 의견을 
담는다. 이를 기능 설계 참고로 사용한다. 제안된 기능을 이미 구현된 기능으로, 글로벌 선사의 환적 요구를 중소 
포워더의 유료 수요로 해석하지 않는다.
[W3] 
 
 
 
 
기존기능을축소해서설명하지않기
Port-i 공개 안내(2026.3.3)에는 9 개 터미널 환적상황 통합과 선박·화물 모니터링/이상 탐지가 있다. 기존 예약·
모니터링 체계를 인정하고, 화물별 마감·변경조건·비용을 묶은 판단의 추가 가치를 비교 실험으로 확인한다.

입력과고정조건
동일 화물·출발/수령지·원래 마감을 고정한다. 바꾸는 것은 확인 가능한 차량 터미널 도착 계획이다. 예약이 필요한 
시간창과 차량의 가용시간은 따로 확인한다. 승인에 걸리는 시간을 제외하고 단순히 변경 마감까지 남은 시간만 표
시하지 않는다.
 
 
 
 
 
이번단계에서확장하지않는부가기능
로그인·결제·복잡한 지도·실제 자동 배차는 첫 통합의 필수조건이 아니다. 수리모델과 관측 갱신·대기·대응 계산은 
이번 범위로 유지한다. 항공·지역 확대는 이름만 추가하지 않고 실제 연결과 자료에 따라 판단한다.

실행: Python 3.12 환경에서 아래 명령을 순서대로 실행한다.
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-service.txt
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
브라우저: http://127.0.0.1:8000. Windows PowerShell 활성화는 .venv\Scripts\Activate.ps1. HTML 더블클릭만으로 
Python API 가 실행되지는 않는다.
GitHub Pages + Pyodide 전환은 합의한 검토 방향이며 아직 구현·검사되지 않았다. Render 는 필수가 아니고, 
별도 배포 준비 코드도 실제 공개 서버를 생성한 상태는 아니다. 이번 전달 작업에서는 서버를 만들거나 결제·배포
하지 않는다.
별도 ZIP RDelay_배포준비코드_미배포.zip 은 PR #2 브랜치의 전체 소스 스냅샷이다. 기본 구현 코드와 혼합하지 
않았으며, 실제 서비스 URL 은 없다. GitHub Pages 호환 엔진으로 잘못 표시하지 않는다.
