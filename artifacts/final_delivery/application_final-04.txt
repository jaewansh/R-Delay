컨셉개념도
자료·시나리오 → 계수 추정·SIS/OU → 관측 갱신(PF) → 대기·도착 → 대응 비교
사건 연결: 선박 도착 → 선석 대기 → 선박 작업 → 화물 준비 완료 → 차량 인수·반출 → 도로 이동 → 수령지 도착. 선석 대기는 화물 
준비시각에 한 번만 반영한다. 웹은 입력·표시, Python API 는 동일 계산 엔진을 호출한다.

실행실패대응
공개 기사·통계는 문제와 업무 설계의 근거이며 개별 학습자료를 대체하지 않는다. 신규 지연 사건 수와 현재 지연 수, 발생시각과 이
용 가능시각을 분리한다. 시제품은 10:00 단일 관측만 지원하고 다른 시각은 거부한다. 미래 정보는 넣지 않는다. 실측·추정·합성을 
표시하고 실제 연결은 ID 대응과 이용권을 확인한다.
관측·추정 실패 시 이전 추천을 지우고 경고한다. 예약 미확인·차량 중복·변경 시한 경과는 추천에서 제외한다. 표본·운영로그 부족 시 
합성자료로 모델 기능을 검증하되 현장 정확도·절감 실적이라고 쓰지 않는다. 로컬 실행은 인터넷 없이 새 계산까지 시험한다.
