16  데이터·API 계약
자료군
필수 기록
출처·시각
source_id, data_type(실측/추정/합성), event_time, available_at
관측
observation_type, 값, 구간 또는 표본 수, 누락 상태
화물·실행
익명 ID·선박 연결 ID·원래 마감 사건·차량·예약·시한·승인
재현성
model_version, parameter_set_id, commit, 시드·스트림·실행환경
API 설계
입력·반환
POST /api/v1/calibrations
관측/고정조건 → 추정 모델 ID·진단·학습 구간
POST /api/v1/runs
시나리오/모델/마감/후보 → 실행 ID·처리 상태
GET /api/v1/runs/{id}
SIS·R_d·대기·위험·후보 및 경고
POST /api/v1/runs/{id}/observations
새 관측 → 원본을 보존하는 새 실행 ID
GET /api/v1/runs/{id}/artifacts
설정·결과·진단 기록 저장
외부 시각은 시간대 포함 ISO 형식, 내부는 한 기준시점 이후 h 로 변환한다. 분당/시간당 비용을 혼용하지 않는다. 
긴 계산은 실행 ID 로 진행상태를 조회하고 중복 요청을 구분한다. 응답에는 합성 여부·모델 상태·계산 경고를 필수
로 포함한다.
계산 실패 / 입력 부족 / 확인 필요 / 기준 충족 후보 없음 / 추천 있음은 서로 다른 상태다. 추정·API 오류가 나면 옛 
추천을 현재 결과처럼 남기지 않는다. 늦은 과거 관측은 재처리 규칙과 시간을 보존한다. 위 API 는 이번 개발 명세
이며 현재 배포된 주소가 아니다.
