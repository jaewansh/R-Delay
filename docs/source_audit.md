## A2 — 참가양식
파일: 참가양식.pdf (3쪽). 1~3쪽 본문, 1~2쪽 표 이미지, 3쪽 작성지침을 확인했다.
- 신청정보: 팀명, 작품명, 키워드, 도메인/주 도메인, 작품요약, 지원동기.
- 팀정보: 구분, 성명, 출생연도, 소속대학/전공학과, 학년, 학적상태, 휴대전화/이메일.
- 신청요약/동기 각각 200자 이내. 본 작업은 더 엄격하게 공백 포함 코드포인트 수로 검사한다.
- 키워드 5개 이내.
- 요약표의 내용 행 4개: 기획 배경 / 핵심 컨셉 / 최종 성과물 개발 전략 및 계획 / 비즈니스 모델 및 사업화 방향.
- 상세: 가 기획 배경 / 나-1 핵심컨셉 / 나-2 도메인 융합 / 나-3 개념도 / 다 개발전략 / 라 사업화.
- 컨셉은 요약 포함 최대4쪽, 청색 안내 삭제, 외부 자료 출처 기재. 신청서1쪽과 합해 목표5쪽.

## U — 이번 사용자 제공 설계 기준
SIS·C·R_d 식은 현재 메시지에 제공된 식을 그대로 사용한다. 최초10쪽 초안 전체를 저장소에서 열었다고 주장하지 않는다. SIS, 로그-OU, 입자필터, 시간가변 선석 대기, 계수 추정, 배차, 웹을 모두 이번 대회 구현 목표로 둔다. 추가 연결 가정과 미구현/미실행을 구분한다. 인터뷰는 필수 선행조건으로 두지 않는다. 개인정보는 공란이다.

## 최신 공식 페이지의 접근 제한
https://www.aimobilhack.com/ 및 /apply 직접 열기는 이번 실행에서 Cache miss였다. 따라서 최신 홈페이지 배점·FAQ·추가 규칙을 확인했다고 보고하지 않는다. 제공된 A1/A2를 서식 기준으로 삼고, 변경 가능한 일정·최신 공지는 제출 직전 재확인 사항으로 남긴다.
