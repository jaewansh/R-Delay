# R-Delay 구현·제출 기준 v0.1

문서 성격: 1차 제출·설계 명세. 서비스 구현 완료 보고서가 아니다.

## 서비스와 이번 대회 범위
작품명: R-Delay: 감염병 확산 수리모델 기반 해상·육상 지연 예측·대응 웹서비스.
부산신항→양산권 내륙 수령지의 수입컨테이너 한 건이 초기 적용 시나리오다. 고객·협약·실제 연결자료는 미확보다. 초기 사용자는 내륙운송을 조율하는 중소 포워더 운영담당자라는 가설이다. 차량·예약 실행자, 비용 부담자, 구매자를 구분한다.

SIS, 로그-OU, 입자필터, 시간가변 선석 대기모형, 관측 기반 계수 추정, 배차 의사결정, 웹서비스는 모두 이번 대회 구현 목표다. 미구현은 미구현으로 기록하되 임의로 대회 이후로 옮기지 않는다. 이번 bootstrap 작업에서는 서비스 코드가 아니라 실제 제출 Word·설계 PDF와 문서 생성·검사 코드만 만든다.

## 원안으로 제공된 수식 [U]
```math
\frac{dI_i}{dt}=\beta_i(t)\left(1-\frac{I_i}{N_i}\right)\sum_j C_{ij}(t)I_j-\gamma_i(t)I_i
```
```math
C(t)=\mathrm{Id}+\kappa\tau_0 M(t),\qquad \Gamma(t)=\operatorname{diag}(\gamma_i(t))
```
```math
R_d(t)=\rho\!\left[\operatorname{diag}\!\left(\beta_i(t)(1-I_i/N_i)\right)C(t)\Gamma(t)^{-1}\right]
```
I/N은 동일 의미의 지연·전체 작업 수, β·γ·M은 h^-1, τ₀는 h, C·κ·R_d는 무차원이다. C_ij는 j→i의 영향이다. N이 다른 거점의 비율형에는 N_j/N_i를 보존한다. SIS는 물량 보존 이동식이 아니며 유입·이탈은 별도 설계 대상이다. R_d는 현재 상태에 조건부인 전파 지표이고 화물 마감위험과 같지 않다.

## 사건과 추가 연결 가정
선박 도착→선석 대기→선박 작업→화물 준비 완료→차량 인수·반출→도로 이동→수령지 도착.
SIS 작업 수와 대기열 선박 수를 동일시하지 않는다. 선석 대기는 화물 준비시각에 한 번만 반영한다.
선박 작업 완료와 이송, 문서/인도 조건의 늦은 시각을 화물 준비로 정의하는 것은 추가 설계 가정이다. 인수·반출 처리에 별도의 육상 지연 영향을 적용할 때 동일 작업을 다시 계산하지 않는다. 도로 이동은 반출 이후 구간만 더한다. 특정 화물의 행동이 배경망을 바꾸지 않는 첫 모형 가정을 표시한다.

## 확률·관측
로그-OU는 평균회귀 로그 상태를 통해 양의 전파계수를 생성한다. 랜덤워크와 동일시하지 않는다. OU 전이가 정확해도 SIS 결합 적분의 시간오차 검사는 별도다.
입자필터는 관측 우도·가중치·ESS·재표본추출을 구현 목표로 둔다. 재표본추출은 SIS·로그상태·대기열 상태를 같은 조상 인덱스로 복제한다. 미래 평활화 결과를 실시간 필터링이라고 표시하지 않는다.
신규 지연 사건 수는 구간 생성항 적분에 조건부인 음이항 모형 후보, 표본 n건 중 현재 지연 수는 상한 n을 지키는 베타-이항 후보로 구분한다. 관측모형 구체화는 추가 설계다. event_time과 available_at을 저장하고 예측시각까지 이용 가능한 관측만 쓴다.

## 선석 대기
시간가변 도착률, 동질 서버, 선입선출, 시간가변 지수 서비스 위험률을 첫 모형 가정으로 적는다. Kolmogorov 전진방정식은 시스템 내 선박 수의 분포를 계산한다. 대상 선박의 시작/완료시간은 표적 선박 상태를 별도로 추적한다. 절단 넘침확률과 서비스 중단을 관리하고 마지막 상태에 확률을 숨겨 넣지 않는다. 평균 SIS를 한 번 넣은 계산으로 전체 불확실성을 대체하지 않는다.

## 추정·의사결정
상수 계수 추정과 외생변수 기반 ML은 구분한다. β/γ의 관측 식별성과 κM의 스케일 문제를 검사한다. 과거로 추정하고 이후로 평가한다. 정답 파라미터를 추정 입력에 넣지 않는다. 이번 문서에 과거 대화의 미실행 수치를 성과로 사용하지 않는다.
마감은 원래 수령지의 정의된 사건 기준으로 고정한다. 차량·예약·승인·변경시한을 확인한 후보에서 허용위험을 충족하는 비교비용 최소안을 검토한다. 후보 없음·입력 부족·계산 실패를 구분한다. 비용 미완결/관측 불일치 시 추천을 강제로 만들지 않는다.
